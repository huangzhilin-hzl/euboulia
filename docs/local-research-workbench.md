# 本地研究工作台 · v0.4

此版本保留在 `prototypes/inference-world/research.html`。新方向见 [Loop 工作台 v0.5](loop-workbench.md)。

当前产品方向：一个人和本地 Agent，围绕一个研究方向建立基线、讨论数据、形成假设、逐层分支验证，留下可回溯的经验。多人、远程机器连接和团队身份不再是默认工作流的前置条件。

## 核心流程

方向 → 基线 → 结果与讨论 → 方案分支 → 一轮验证 → 对照与取舍 → 经验。

- **方向**保存研究问题和多个源码、数据、资料引用。可以先提出问题，逐步补齐评测条件。
- **分支**保存假设、父分支、创建时的代码和评测快照、参考结果、来源资料及引用经验。可以从任意已完成的实验继续分叉，也可以从尚无实验的方案继续拆分。
- **实验**保存来源、状态、固定评测条件、代码版本、指标、结果说明和原始记录位置。结束后的记录不随分支后续修改而变化。
- **讨论**归属于分支；可引用实验和资料。一条讨论可直接生成新的验证分支。
- **外部线索**保存原文、日期或版本、与问题的关系和适用条件，始终与本地测量证据区分。可以带着来源创建子分支。
- **经验**保存结论、适用范围、实验引用以及判定历史。草稿、用户判定复验、存在反例三个状态可追溯。条件变化时提示复验。

研究树负责定位，页面主区按“当前发现、数据对照、讨论、下一步”排列。实验详情与原始日志按需展开。深层分支、暂停路径和历史失败均保留。

## 这一版实现的原型能力

- 无需登录的方向入口与最近研究；预置一项明确标识的推理优化样例。
- 分支任意继续分叉，选择实验快照作为起点；暂停、恢复、收束与重新开放。
- 可引用数据柱形或记录的分支讨论；讨论转分支并保留独立上下文。
- 演示验证有轮次/时间预算、单执行位排队和约束超限返回讨论。暂停释放执行位；刷新后中断并保留记录，不自动重放。
- 实验手动录入与 JSON 文件填充；标记为“用户录入 · 未核验”。
- 跨分支选择实验对照。只有相同数据、环境、评测方法、指标和来源类型才计算变化率；未确认的条件和混合示例/用户结果不给出改进百分比。
- 外部参考资料、条件、版本和验证分支回引。
- 经验草稿、复验/反例判定历史、证据回链、跨研究引用与条件变化提示。
- 独立的浏览器存储、每分支草稿、表单草稿、全文搜索、备份导出/校验导入，以及四套外观模式。

## 交互演示与真实执行的边界

该版本完成产品交互，不调用模型、不启动实验进程，也不自动读取任意源码路径或获取网页内容。演示回复和数值来自确定性样例，界面保留来源标记。自由讨论只保存用户输入，不伪造模型回答。

用户导入的 JSON 仅在浏览器内读取。`artifact` 路径或链接是原始记录引用，工作台不会自动打开或核验它。备份不是执行指令；恢复备份不会执行命令。

研究分支目前是可持久化的产品记录。真实 Git worktree、代码 checkout、多目录读写和实验执行隔离留给后续本地执行器。当前不会为每条分支创建真实 Git 分支。

后续接入真实执行时，应把任务预算、原始数据、代码/数据版本、运行进程归属及中断恢复映射到既有执行契约。研究结束和“已复验”标签不能替代真实的正确性及性能验收。

- [AI Scientist-v2](https://arxiv.org/abs/2504.08066)：从假设到实验、分析和树状探索的研究循环。

这些是产品设计参考，不表示本原型集成了上述服务。
