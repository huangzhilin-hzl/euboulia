| 实际操作 | 检查结果 |
| --- | --- |
| 首页创建「长上下文研究」研究室 | 进入空研究室；没有继承 DSV4 的模型或算力 |

| 自由讨论中的消息转为目标 | 原消息保持原线程，新目标保留来源回链 |
| Prism 的 Profile 讨论转为新目标 | 表单带入原消息和 Trace 引用；新目标产物仅显示携带的证据，没有混入 MHC 对比 |
| 收起再打开发起目标表单 | 研究问题、完成标准与所选负责人保留 |
| 暂停目标再恢复，刷新页面 | 状态恢复，目标输入草稿仍在 |
| 尚有未结束工作时尝试结束研究 | 表单内显示具体原因，目标不被结束 |
| 从目标详情回到来源讨论 | 跳转到原 Goal 的原消息，并保留新目标入口 |
| 补充目标的完成标准，再打开已有工作 | 历史目标说明保留；已有工作显示依据第 1 版，当前目标为第 2 版 |
| 搜索新目标并打开 | 正确进入匹配的研究室与目标上下文 |
| 切换雾白、石墨、奶油黄、暖绿 | 新入口与创建表单沿用主题；石墨表单无水平溢出 |

以上操作没有调用真实 Agent、模型 API 或 GPU。任务交付与目标结论是人工输入的本地演示记录。

控制台未发现警告或错误。验收后复位本轮测试数据，并清除临时视口设置，保留研究室首页供演示。
