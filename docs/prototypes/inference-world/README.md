# 本地研究工作台 · v0.4 交互原型

从一个方向开始，与本地 Agent 围绕结果讨论、逐层分支验证，并沉淀有条件、有证据的经验。默认入口不需要登录、研究室或 Agent 配对。

[产品设计与边界](../../local-research-workbench.md)。持续开发通过英文 PR 合入 `molou/inference-world-design`；固定演示分支 `molou/inference-world-demo` 不变。

## 打开

从仓库根目录运行：

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory docs
```

访问 [本地工作台](http://127.0.0.1:8772/prototypes/inference-world/)。也可以使用已有的 `uv run euboulia lab serve`，访问同一路径的 8773 端口；默认工作台不会调用 Lab 鉴权 API。

原型无需 npm 安装或构建。所有图标、样式和脚本随仓库提供。

## 一条完整演示路线

1. 首页点击“继续研究”，进入示例的“调整批处理策略”。当前发现优先显示吞吐改善与尾延迟代价，所有数值标为示例。
2. 点击图上的 P95 柱形，记录随问题进入讨论。输入自己的判断并保存，点击该讨论下的“从这个想法创建分支”。
3. 给新方案命名并说明假设，选择已完成实验为起点。新分支保存当时的条件和代码版本；可以继续在分支里面创建分支。
4. 点击“演示验证”，约定探索方向、最多轮次和时间。每轮演示约 5 秒。超过约束或用完预算时，返回结果供讨论；多个分支使用同一个演示执行位。
5. 在运行条暂停、恢复或结束验证。刷新运行中的页面，记录变为中断，不自动重放。通过明确的新一轮演示继续。
6. 在“对照”中选择基线与不同分支的结果，查看指标、来源、数据、环境、代码版本。条件不同或混合示例/用户数据时，只展示原值，不给出改进百分比。
7. “参考资料”可添加论文、官方文档和 Issue，记录日期/版本、相关性、适用条件；由资料创建验证分支，保留出处。
8. 在对照页“整理为经验草稿”，勾选支持记录、写出结论与适用条件。到经验库查看证据、补充复验/反例判定，再引用到当前分支。改变条件后会提示需要复验。
9. 分支右上角“···”可记录阶段结论并收束；已完成结果和子分支保留，之后可重新开放。
10. 返回首页输入自己的方向。评测条件可逐步补充；从“实验”录入实际测量，或用 JSON 文件填入表单。自己的研究不会自动产生假测量或模型回答。

## 测量 JSON

从“录入实验结果 → 从 JSON 文件填入测量数据”选择文件；先预览填入的表单，再保存。示意格式：

```json
{
  "metric": 1000,
  "guard": 48,
  "codeRef": "commit-or-version",
  "summary": "在固定工作负载下完成三次测量，记录中位吞吐与尾延迟。",
  "artifact": "/absolute/path/to/original-report.json"
}
```

`metric` 为主指标数值；只有设置约束时才需要 `guard`。`codeRef`、`summary`、`artifact` 必填。可以附加与分支一致的 `protocol`；存在不一致时拒绝填入。文件最大 256 KB，只在浏览器读取。

结果标为“用户录入 · 未核验”，原型不会读取 `artifact` 指向的文件，不会宣称结果已经复现。创建经验后，“已复验”由用户给出判定依据，至少关联两份同条件、同来源类型的实验；旧判定保留。

## 保存与外观

- 工作台使用独立的 `euboulia.local-research.v1` 存储。研究室 v0.3 数据和真实 Agent 身份不会被迁移、清空或修改。
- 每条分支的讨论草稿与表单草稿独立保留。⌘/Ctrl K 搜索方向、分支、讨论与经验。
- 顶部备份按钮展示完整 JSON，可下载文件或复制完整内容保存。首页或“原型说明与备份”可校验并导入备份；替换前要求确认，未完成的演示不会自动重放。
- 检测到其他标签页更新时，本页停止写入并提示先导出再刷新；存储损坏或空间不足时保留原内容并显示提示。说明页提供原始数据导出。
- 外观延续雾白、石墨、奶油黄、暖绿四套模式，单独保存；重置演示不重置外观。

## 实现与边界

- `index.html`、`research.mjs`、`research.css`：v0.4 工作台。
- `research-state.mjs`：研究记录、固定快照、讨论、演示队列、比较、经验与备份校验。
- `team.html`：保留的 v0.3 研究室及历史 Agent 连接，参见 [原使用说明](team-readme.md) 和 [连接指南](../../lab-agents.md)。
- `network.html`：保留 v0.1 执行关系原型。

这是交互原型。演示验证与 Agent 回复来自明确标识的固定规则，不调用模型、不执行命令、不自动搜索网页。研究分支不是实际 Git checkout；真实文件隔离、本地执行器与自动检索是后续接入工作。真实 Lab API 仍保留原有鉴权边界。
