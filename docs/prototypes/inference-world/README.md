# 共享研究室 · v0.2 交互原型

对应 [完整产品设计](../../inference-world.md)。默认入口已从任务图改为人和 Agent 共同工作的研究室。它是独立静态原型，未接入生产控制台。

## 演示版本

演示分支：`molou/inference-world-demo`，保存于 2026-09-07。包含共享研究室交互、四套可切换主题、原 v0.1 任务图及验收记录。

演示状态保存在浏览器本地，不随 Git 分支同步。首次打开使用内置样例；再次演示前可在界面中重置演示，外观偏好会保留。

## 本地打开

从仓库根目录运行：

```sh
python3 -m http.server 8772 --bind 127.0.0.1 --directory docs
```

打开 [共享研究室](http://127.0.0.1:8772/prototypes/inference-world/)。使用 HTTP 加载 ES modules，无 npm 依赖或构建步骤。端口占用时可换一个端口。

## 外观模式

左下角「外观」可即时切换四套主题：

| 模式 | 配色方向 |
| --- | --- |
| 雾白（默认） | 中性浅灰、白底与靛蓝强调，适合先从清晰的工作界面开始 |
| 石墨 | 冷灰深色与柔和紫色，减少大面积亮底 |
| 奶油黄 | 暖纸底色、明快黄色导航栏，边角更利落 |
| 暖绿 | 保留原有低饱和绿色基调，提高辅助文字对比度 |

主题覆盖对话、图表、证据详情、输入框与弹窗。选择单独保存到浏览器；刷新、切换研究室或重置演示都不会重置主题。选择器支持键盘方向键和 Esc；切换外观不清空消息或草稿。

`themes.css` 提供所有配色变量；`appearance.js` 在首次绘制前恢复主题，并管理独立的外观选择器。仅用于 v0.2 研究室，v0.1 旧任务图保持原样。

## 体验路线

1. 在讨论中打开「Profile · Decode 等待窗口」，点击示意时间线中的等待区间。证据引用与问题进入输入框，勾选「交给队友办」、选择 Prism 后发送。
2. 切到「工作」，查看任务的来源、负责人、引用。演示开始、暂停与恢复；GPU 工作恢复后重新排队，不会与另一项测量同时占用演示资源。
3. 回到讨论，点顶部「1 个方向待定」直达决策卡，选择补采多 rank。工作列表与研究关系随之更新。
4. 打开 MHC 对比，查看示例 TPOT、吞吐、测量范围和缺失的正确性。保存经验草稿后在「经验」里查看；草稿仍标为未验证。
5. 在「计算机」演示 H20 连接中断，回到工作列表查看「受阻」；Computer 上的分析不受 GPU 连接影响。恢复后 GPU 工作回到队列。
6. 输入草稿后切换研究室，再返回；刷新页面，消息、任务、草稿和引用仍保留。数据只保存在当前浏览器、当前 origin。
7. 试试 @ 队友、搜索（⌘/Ctrl K）、任务筛选、原讨论回链、方向补充；小屏通过右上导航按钮切换研究室。

所有功能在本地演示空间运行。用户消息不会发送到 Raft 或真实队友。

## 实现与边界

- `index.html`、`room.css`、`room.mjs`：v0.2 研究室界面与交互。
- `room-state.mjs`：本地演示状态、消息转任务、方向选择、暂停/恢复、离线阻塞与存储恢复。
- `network.html`、`styles.css`、`app.mjs`、`model.mjs`：保留的 v0.1 任务图原型，用于审阅动态依赖、预算、晋升和回滚契约。
- 两个原型状态独立。v0.2 使用 `localStorage`，v0.1 使用页面内存。
- 不调用模型、Agent、Kubernetes、真实运行记录或 provider API。自由文本不会触发假 AI 回复；交办只保存到本地队列，未解析实际资源需求。
- Trace 是标识清楚的示意窗口；实验数字、队友、计算机和经验都是固定样例；没有原始 trace 或真实 diff。
- v0.2 关系页是示例概览，展示方向变化；不是通用动态图编辑器。v0.1 的原动态任务图仍可从关系页进入。
- GPU 断连恢复只演示 UI 状态。生产需要核对已有 Pod、Attempt、租约和副作用，不能照搬原型重新派发。
- 本地持久化验证用于容错，不能替代生产鉴权、多人冲突处理和服务端输入校验。

