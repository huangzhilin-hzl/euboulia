# 推理优化世界 · 可交互原型

对应 [完整产品设计](../../inference-world.md)。这是独立静态原型，未接入生产控制台。

## 本地打开

从仓库根目录执行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory docs
```

打开 [任务网络](http://127.0.0.1:8767/prototypes/inference-world/)。使用 HTTP 服务加载 ES modules；不需要 npm 安装或构建。若端口已占用，选择其他端口并相应修改 URL。

## 建议体验路线

1. 在默认选中的 T1 点击“演示交付”，查看状态与产物历史；另一次重置后可以试“演示回退”或“演示失败”。回退不等于执行失败。
2. 选择 P1，认领并交付候选 Profile。可在 T1 运行时启动，它会使用另一套空闲 H20 资源。
3. 选择 V1，认领并交付判定；随后对 E1 做同样操作，查看第一条经验草案。
4. 在 E1 开启下一轮。新子图固定当前 champion 为父版本，同时保留根 B0；“版本谱系”可看到继承关系。
5. 选中任意任务，打开“讨论”，保存判断后转为假设；或者直接用顶部按钮提出方案。
6. 在“连接任务”中尝试把 V1 连回 H1，查看环检测。合法依赖修改会递增图版本；已发生任务的输入不可改写。
7. 打开“成员与资源”，将 Prism 的日预算设为 1，再查看待接力任务的准入原因。资源离线不会释放其运行中的租约。
8. 打开“经验与 RSI”，演示经验复现和关联反例。候选 Practice 只有评测、有限试用都通过后才可晋升；回滚会保留发布历史，已创建任务的方法版本不变。

画布可拖动、缩放、切换列表；点击节点高亮上下游并查看详情。长依赖绕开中间节点。小屏上检查器位于画布下方，列表可用键盘操作。

## 演示边界

- 所有状态仅在页面内存中；刷新或“重置演示”会清除本页操作。
- 不调用 Agent、模型 API、Kubernetes 或真实 run；不发送讨论，不消耗真实 token/GPU。
- “演示交付”合并了提交与验收步骤，不能作为生产完成协议；2,000 token 为固定演示结算量。
- 性能通过/回退由演示按钮指定，不包含真实统计比较；原型不提供真实 trace 时间线。
- 成员、Computer、GPU 池为固定示例，注册、登录和权限接口未实现。
- Practice 的 12 个案例及计数为固定演示，未运行真实评测。经验复现按钮也只演示状态转移。
- 生产方案需要图事务、版本化产物校验、租约协调、预算实测、独立 Evaluator 和管理员授权；详见设计文档。

## 验证

```sh
node --test tests/web/*.test.mjs
node --check docs/prototypes/inference-world/app.mjs
```

状态测试覆盖依赖与准入、独占资源、预算预留、失败重试、环检测与历史保护、性能回退、跨轮父版本/B0 参照、过期父分支的晋升冲突，以及方法评测、试用、晋升和回滚。

人工浏览器验证：桌面任务闭环、讨论转假设、依赖错误、预算阻塞、方法晋升及回滚；390px 小屏的任务列表、资源、经验页面。全部仅使用演示状态。
